# IVスキャン

Pokémon GOの「博士に調べてもらう」画面のスクリーンショットから、攻撃・防御・HPを端末内で読み取るPWAです。画像のアップロードや保存は行いません。

## ローカル起動

静的ファイルを配信できるサーバーでこのディレクトリを公開します。例:

```powershell
npx serve .
```

表示されたURLを同じネットワークのiPhoneから開きます。公開時はGitHub PagesやCloudflare PagesなどのHTTPS対応ホスティングを利用できます。

## 現在の対応画面

- 縦向きのiPhoneスクリーンショット
- チームヴァーラー（オレンジ・赤系の評価バー）
- 3本の評価バーがすべて表示された状態

端末サイズやゲームUI変更に備えて、判定画面から読み取り位置を確認できます。
